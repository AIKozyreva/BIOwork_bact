Попыталась собрать в одну среду всё (почти), что можно вроде как использовать для метагеномики полногеномной. 
Создала файл .yml по которому можно создать чистое окружение конды, куда всё установится, в которое автоматически подгрузятся некоторые переменные среды тоже, чтоб не надо было их задавать руками. Вот путь до этого файла и команда, с помощью которой можно создать новое окружение: conda env create -n metagen3v3 -f /path/to/meta3v3_env.yml.

Полезное: 
Можно установить себе такую штуку как `conda-merge` - позволяет соединять содержимое двух окружение в один файл, при этом оставляет наиболее актуальные версии в конечном файле, например `conda-merge ./env1.yml ./env2.yml > env12.yml` . 

[-] Команда, чтобы сохранить переменную в данные окружения conda env `config vars set TMP_VAR=/path/to/somewhere`
[-] ---------------- чтобы просмотреть все переменные в данных активного окружения `conda env config vars list`
[-] ---------------- чтобы удалить переменную из пост-х данных окружения `conda env config vars unset CHECKM_DATA_PATH`
[-] Команда, чтобы экспортировать все пакеты окружения, котоыре вы себе скачивали в файл yml, который можно использовать для создания другого окружения `conda env export -n my_env --from-history --no-builds | head -n -1 > my_env.yml`

Ещё, хз как у вас, но у меня ни в один профиль не установился через конду Genomad (определяет, профаги, плазмиды, резистентности в контигах, сборках и даже длинных ридах). Поэтому теперь у нас есть его докер-image `antoniopcamargo/genomad` --> можно запускать контейнер. Используйте его внимательно, если вы каждый раз запускаете новый контейнер, каждый раз в него по инструкции с оф.документации скачиваете в него бд, потом делаете свои дела и не убиваете контейнер - таки штуки будут висеть в памяти и быстро её забивать. Либо убивайте контейнер после использования, либо всегда используйте один и тот же контейнер под себя, либо скачайте бд и дополнительно привязывайте место хранения бд на сервере к контейнеру, чтобы внутри контейнера после запуска бд уже лежала. 

Вот инструкция использования контейнера с оф.документации Genomad: 
```
docker run -ti --rm -v "$(pwd):/app" antoniopcamargo/genomad download-database . 
docker run -ti --rm -v "$(pwd):/app" antoniopcamargo/genomad end-to-end input.fna output genomad_db
```
